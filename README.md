# 📊 E-Commerce Analytics Dashboard

An interactive dashboard built with **Streamlit**, **Python**, and **MySQL** to visualize e-commerce customer behavior and sales data.

## 🚀 Features
- **Database Integration**: Connects directly to MySQL for real-time querying.
- **Interactive Data Preview**: Displays dynamic dataframes for user profiles and transactions.
- **Clean Architecture**: Efficient SQL schema design with foreign key relational mapping.

## 🛠️ Tech Stack
- **Frontend**: Streamlit
- **Backend/Database**: MySQL
- **Data Manipulation**: Pandas
- **Language**: Python
